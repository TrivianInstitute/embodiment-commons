# Accessibility and learner choice

[Home](../README.md)

No single posture, sensory channel, mobility pattern, or emotional response defines participation. Ask what format helps without requiring a diagnosis. Accessibility is a design responsibility, not a reward for disclosure.

| Default invitation | Equivalent alternative |
| --- | --- |
| Notice breathing | Notice an external feature or write the task question |
| Change position | Remain still and change attention, or take an ordinary break |
| Look around | Listen, notice contact, or use a familiar mental map |
| Write a reflection | Dictate, speak privately, draw, or think without recording |
| Join a group discussion | Respond privately, work in a pair, or analyze a fictional example |
| Pause a screen | Keep necessary assistive technology active |

Offer text in advance, meaningful headings, plain language, and adequate time. Avoid relying on color, imagery, gesture, or audio alone. Do not require closed eyes, eye contact, stillness, standing, breath manipulation, touch, camera use, or disclosure. Provide choices at the start rather than waiting for someone to identify themselves publicly.

If an alternative does not provide equivalent access, invite feedback and revise. These initial materials have not undergone a formal accessibility audit or learner co-design. Report barriers to learn@trivianinstitute.org without sharing private health information.
